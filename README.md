# 5-stinger

Starfall-чип «Стингер» (ПЗРК) для Garry's Mod.

Файл: [`stinger.lua`](stinger.lua)

## Как работает

1. Владелец чипа берёт `weapon_rpg` → по центру прицела рисуется круг захвата.
2. Любой живой игрок, попавший в этот круг (и не закрытый стеной), берётся на
   захват: круг краснеет, на цели появляется пульсирующая метка, снизу пишется
   `LOCK`. Захватывается ближайшая к центру прицела цель.
3. Выстрел с захватом → обычная ракета убирается, вместо неё летит
   самонаводящаяся ракета (голограмма + трасса). Она доворачивает к цели и
   подрывается при попадании, рядом с целью или по истечении времени.
   Без захвата ракетница стреляет как обычно.

## Настройки

В начале файла всего две:

```lua
local DMG          = 120  -- урон в эпицентре взрыва
local BLAST_RADIUS = 300  -- радиус взрыва (юниты)
```

Остальные числа (угол и дистанция захвата, скорость и время жизни ракеты) —
внутренние, их можно спокойно оставить как есть.

## Установка

1. Поставить Starfall Processor, открыть редактор, вставить код `stinger.lua`.
2. Чип ставится **обычным** процессором (не `--@superuser`), владелец чипа =
   стрелок. Круг рисуется только на HUD владельца.
3. Взять `weapon_rpg`.

## Какие библиотеки используются

`find`, `trace`, `hologram`, `effect`, `sound`, `game`, `net`, `render`,
`timer`, `hook`.

- Урон идёт через `game.blastDamage` (нужен `game.blastDamage` — по умолчанию
  требует прав администратора), а если сервер его запрещает — чип сам считает
  урон по сфере через `find.inSphere` + `entities.applyDamage` (нужно разрешение
  `entities.applyDamage` на игроков/NPC).
- Удаление ванильной ракеты — `entities.remove`; если проп-защита сервера
  запрещает, чип не ломает выстрел (своя ракета просто не пускается).
- HUD требует разрешения `render.hud` (по умолчанию у владельца чипа есть,
  плюс чип сам вызывает `enableHud`).
